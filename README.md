Converted from the supplied HTML dashboard into a Vite + React application.

```bash
npm install

```

## Included interactions

- Dashboard filter pill state
- Inventory X-Ray modal
- ESC / outside-click modal close
- Quick Action floating menu
- Preserved Liquid Glass CSS, SVG charts, typography, gradients and responsive layout

The original Tailwind CDN configuration is retained in `index.html` so the supplied utility classes continue to render.
